**The Awkward Age** - 2D платформер с уникальной механикой смены возраста персонажа, разработанный для PC, во время LOWREZJAM 2026. (https://itch.io/jam/lowrezjam-2026)
  **Главная особенность:** В соответствии с правилами джема, игра создана со строгим ограничением разрешения экрана — всего **64x64 пикселя**, развернутых под современный формат.

**Рабочая версия Unity**: 6000.5.5f1

**Как запустить игру?**
**Способ 1**:
  1. Скачать zip файл с Гита.
  2. Разархивировать его.
  3. В Unity Hub с помощью кнопки "Add" добавить файл в список проектов.
  4. Запустить проект.
  MainMenu - основная сцена для запуска игры.
**Способ 2**:
  Запустить демку игры на Itch.io. (https://offtiex.itch.io/the-awkward-age)

**Архитектура проекта** находится по пути Assets/Scripts.
